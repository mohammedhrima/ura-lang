## 001 — loop: loop (infinite) with break + continue

```ura
// stdout: 1 2 4 5
// expect: 0

fn main() i32:
    i i32 = 0
    while True:
        i = i + 1
        if i == 3:
            continue
        if i == 6:
            break
        io::out($"{i} ")
    io::out("\n")
    return 0
```
