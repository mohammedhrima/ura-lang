## 007 — try: return inside a try returns from the function

```ura
// stdout: ret = 5
// expect: 0
use "@/core"

fn pick() i32:
    try:
        return 5
    catch e Error:
        return 0

fn main() i32:
    io::out($"ret = {pick()}\n")
    return 0
```
